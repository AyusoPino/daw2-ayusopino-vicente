# Estructuras

## Arrays
> Permite almacenar una colección de datos a los que permite acceder de forma aleatoria.

### Métodos
| Método         |           Descripción                       |
|----------------|---------------------------------------------|
| new Array()/[] | Crear el array                              |
| push()         | Añadir un elemento al final                 |
| splice()       | Añadir o eliminar elementos                 |
| at()           | Obtener el valor almacenado en una posicion |
| sort()         | Ordenar el array                            |
| includes()     | Saber si contiene un elemento               |
| find()         | Buscar el elemento que pasa la prueba       |
| length         | Conocer la longitud del array               |
