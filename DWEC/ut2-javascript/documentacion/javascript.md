# Estructuras

## Arrays
> Permite almacenar una colección de datos a los que permite acceder de forma aleatoria.

### Métodos
| Método         | Descripción                                      |
|----------------|--------------------------------------------------|
| new Array()/[] | Crear el array                                   |
| push()         | Añadir un elemento al final                      |
| pop()          | Eliminar y devolver el último elemento           |
| shift()        | Eliminar y devolver el primer elemento           |
| unshift()      | Añadir un elemento al principio                  |
| splice()       | Añadir, eliminar o reemplazar elementos          |
| slice()        | Obtener una parte del array sin modificarlo      |
| at()           | Obtener el valor almacenado en una posición      |
| sort()         | Ordenar el array                                  |
| reverse()      | Invertir el orden de los elementos                |
| includes()     | Saber si contiene un elemento                     |
| indexOf()      | Obtener la posición de un elemento               |
| find()         | Buscar el primer elemento que cumple una prueba  |
| filter()       | Obtener los elementos que cumplen una condición |
| map()          | Crear un nuevo array transformando los elementos |
| forEach()      | Ejecutar una función para cada elemento           |
| length         | Conocer la longitud del array                    |


## Set
> Permite almacenar valores únicos de cualquier tipo, ya sean valores primitivos o referencias de objetos.

### Métodos
| Método      | Descripción                                  |
|-------------|----------------------------------------------|
| new Set()   | Crear un Set                                 |
| add()       | Añadir un elemento                            |
| delete()    | Eliminar un elemento                          |
| has()       | Comprobar si contiene un elemento             |
| clear()     | Eliminar todos los elementos                  |
| size        | Conocer la cantidad de elementos              |
| values()    | Obtener los valores almacenados               |
| keys()      | Obtener los valores almacenados como claves   |
| forEach()   | Recorrer todos los elementos                  |


## Map
> Permite almacenar pares de clave y valor. Cada clave es única y puede ser de cualquier tipo.

### Métodos
| Método      | Descripción                                  |
|-------------|----------------------------------------------|
| new Map()   | Crear un Map                                 |
| set()       | Añadir o modificar un par clave-valor        |
| get()       | Obtener el valor asociado a una clave        |
| has()       | Comprobar si existe una clave                |
| delete()    | Eliminar un par clave-valor                  |
| clear()     | Eliminar todos los elementos                 |
| size        | Conocer la cantidad de pares almacenados     |
| keys()      | Obtener todas las claves                     |
| values()    | Obtener todos los valores                    |
| entries()   | Obtener los pares clave-valor                |
| forEach()   | Recorrer todos los pares                     |


## String
> Permite almacenar y manipular cadenas de texto.

### Métodos
| Método         | Descripción                                      |
|----------------|--------------------------------------------------|
| String()       | Crear o convertir un valor en una cadena         |
| length         | Conocer la longitud de la cadena                 |
| at()           | Obtener el carácter de una posición              |
| charAt()       | Obtener el carácter de una posición              |
| includes()     | Comprobar si contiene una cadena                 |
| indexOf()      | Obtener la posición de una cadena                |
| startsWith()   | Comprobar si comienza con una cadena             |
| endsWith()     | Comprobar si termina con una cadena              |
| slice()        | Obtener una parte de la cadena                   |
| substring()    | Obtener una parte de la cadena                   |
| toUpperCase()  | Convertir la cadena a mayúsculas                 |
| toLowerCase()  | Convertir la cadena a minúsculas                 |
| trim()         | Eliminar espacios al principio y al final        |
| replace()      | Reemplazar una coincidencia                      |
| replaceAll()   | Reemplazar todas las coincidencias               |
| split()        | Dividir la cadena y crear un array               |
| concat()       | Unir cadenas                                     |
